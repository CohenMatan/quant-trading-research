# X975: True TTM validation (infrastructure, D113)

- **What it does:** builds True TTM values (four newest visible quarters, fiscal-year reconciliation) from vendor quarterly reports through the point-in-time layer, for the 403-company sample. It compares each value with the authoritative SEC TTM for the same four quarters (as first filed) and checks the availability date.
- **Never:** orders, rankings, returns or exported vendor values (ratios, dates and reasons only).
