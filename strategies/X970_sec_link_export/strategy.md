# X970: SEC-link identifier export (infrastructure, D111)

- **What it does:** walks the 2010–2021 universe and exports identifiers only — each vendor report's CIK, period end, file date and accession (for the SEC timing comparison), the CIKs of companies QuantConnect covers, the liquid securities that have no fundamentals (the D043 population: tickers, months, last date seen) and the financial-format disagreement stock-months.
- **Never:** orders, rankings, returns or fundamental values.
